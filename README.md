# STAT 4052 Final Project

## Project Description
This project analyzes behavioral factors associated with household food waste using multiple regression methods.

## Files
- analysis.R: main analysis and results visualization
- data_processing.R: data cleaning and preprocessing steps
- run_models.R: implementation of LASSO, Post-LASSO OLS, Ridge, Beta regression, and Random Forest

## Dataset
D2D 2016 Food Study (University of Minnesota Data Repository)

## Methods
- LASSO regression
- Post-LASSO OLS with HC3 robust standard errors
- Ridge regression
- Beta regression
- Random Forest

## Requirements
This project requires the following R packages:
- tidyverse
- glmnet
- betareg
- randomForest
- sandwich
- lmtest

- 
## How to run
Run scripts in the following order:
1. data_processing.R
2. run_models.R
